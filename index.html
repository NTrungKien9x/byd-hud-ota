Bản V2 — Màn hình đời 2636

Dành cho mạch GUITION JC3636W518C có tem hộp SKU 10120003 (2636). Nạp trực tiếp qua cáp USB-C trên Chrome / Edge.

Hãy mở trang này bằng Chrome hoặc Edge trên máy tính. Tải .bin V2

1. Hướng dẫn nạp Firmware lần đầu qua USB (Web Flasher)

  1. Mở trang web này trên máy tính bằng Google Chrome hoặc Microsoft Edge.
  2. Cắm cáp USB-C truyền dữ liệu từ máy tính vào màn hình HUD (nếu máy chưa nhận cổng COM, giữ nút BOOT rồi cắm cáp).
  3. Chọn đúng bản V1 (SKU 10120005) hoặc V2 (SKU 10120003) theo tem trên hộp rồi bấm NẠP QUA USB → chọn cổng COM ESP32-S3 → Install.
  4. Chờ nạp xong 100%, HUD sẽ tự khởi động lại với đầy đủ bootloader, phân vùng OTA 16MB và chương trình mới nhất.

2. Hướng dẫn cập nhật Online không cần cáp (WiFi OTA)

  1. Vuốt từ mép trên màn HUD xuống → bật WiFi và kết nối HUD với WiFi 2.4GHz có Internet (qua cổng http://192.168.4.1).
  2. Mở trang quản trị HUD trên điện thoại theo địa chỉ IP hiện trên ô WiFi của HUD.
  3. Tại mục Cập nhật Firmware Online (GitHub OTA), kiểm tra đường dẫn OTA trùng với link dưới đây:
  1. Bấm KIỂM TRA BẢN MỚI → CẬP NHẬT ONLINE trên web, hoặc vuốt mở Menu nhanh trên HUD rồi chạm nút CẬP NHẬT OTA (sáng xanh khi đã nối WiFi). HUD tự chọn đúng file V1/V2 theo mạch, hiện vòng tiến trình 0–100% và tự khởi động lại!
